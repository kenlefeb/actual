# Release 26.10.1-alpha.12 — Ken’s Actual fork

October 28, 2026

**Unofficial fork prerelease.** Based on Actual 26.10.0 (`2bebdbaae0b701120a8cad9d56aafd64fa04c577`); not an official Actual Budget release.

Three paycheck fixes: percent splits now always add up to net pay, and two kinds of invalid paycheck are refused before anything is saved.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- No new fork features in this release; earlier features are retained.

#### Enhancements

- No new fork enhancements in this release; earlier improvements are retained.

#### Bugfixes

- Paychecks split entirely by percent now save when net pay ends in an odd cent. When the percents add up to 100% and there is no "remainder" deposit, the last deposit takes the leftover cent, so the deposits always add up to net pay.
- A paycheck whose deposits go to two accounts with the same name is refused with a clear message. Before, saving it left stray schedules behind and the paycheck could never be saved.
- A paycheck with a deduction that transfers to an account deleted elsewhere is refused before anything is saved. Before, choosing "create a new clearing account" left an empty account behind.

#### Maintenance

- Fork pull requests now run typecheck, lint and tests on GitHub-hosted runners, and must pass before they merge.
- Agent workflow: fork backlog tracked as Shortcut stories; the Impatient Programming primer is part of the fork.

#### Known limitations

- Experimental and off by default; the paycheck editor is desktop only.
- "Upcoming dates" in schedule and paycheck editors does not reflect skipped dates.
- Each deposit must go to a different account, and every paycheck repeats its defined amounts; edit a posted transaction for a one-off change.
- Imported deposits more than about 7.5% from the expected amount do not link automatically.
- Releases published on the same day may show the "What's new" message for any of them; the Notifications page lists all.
- Synthetic staging only; no real financial data or production paperwork migration. No iPhone acceptance test is claimed.
