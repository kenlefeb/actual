# Release 26.10.1-alpha.2 — Ken’s Actual fork

October 26, 2026

**Unofficial fork prerelease.** For Ken’s synthetic staging evaluation, based on Actual 26.10.0 (`2bebdbaae0b701120a8cad9d56aafd64fa04c577`). This is not an official Actual Budget release.

Desktop transaction notes now retain and expose multiple lines, including notes created on the phone. This fixes a reproduced desktop editing path that removed line breaks; the original phone-pilot incident has no client event trace establishing its exact origin.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; the accompanying `image.ref` and `image.id` identify the exact tested artifact).

#### Features

- No new product features; this release corrects transaction-note behavior.

#### Enhancements

- Show a multiline desktop note editor. Use Shift+Enter for a new line; Enter and Tab retain table navigation.
- Display the full multiline note on hover even when it fits horizontally. The transaction table retains its compact row layout.

#### Bugfixes

- Replace the single-line desktop input that stripped newlines when editing or blurring a note.
- Keep typing and arrow keys inside the multiline editor; retain beneficiary tag completion and existing quick-entry shortcuts.

#### Maintenance

- Add failing-before/fixed-after regressions for newline preservation, multiline editing and full-note previews.
- Extend browser acceptance to edit a mobile split without changing its parent or sibling, then edit the same multiline parent note on desktop.
- Align all seven package versions and Settings on `26.10.1-alpha.2` and include the desktop regressions in release CI.

#### Known limitations

- Synthetic staging only. No migration of real financial records or production paperwork.
- This release prevents the reproduced newline loss; it cannot infer missing line breaks in arbitrary historical notes.
- Automated mobile-browser checks do not replace acceptance on Ken’s installed iPhone PWA.
