# Release 26.10.1-alpha.21 — Ken’s Actual fork

November 1, 2026

**Unofficial fork prerelease.** Based on upstream Actual `master` at `21c2b3f703142f858af4c653a31e675ca5ff85d7` (October 26, 2026), which comes after Actual 26.10.0 and is not itself an upstream release; not an official Actual Budget release.

This release adds an MCP server, so an AI assistant on your computer can look up your budget; it is read-only unless you turn on writes. It also adds a Notifications row to the phone Settings list and fixes several schedule, Move on budget and release-news details.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance). The release artifact also carries the MCP server as `mcp/mcp.js`, with its `package.json` and `provenance.json`.

#### Features

- An MCP server (`@actual-app/mcp`) lets an AI assistant that speaks the Model Context Protocol, such as Claude Code or Claude Desktop, look up accounts, categories, payees, transactions, budget months, schedules, paychecks and business calendars in your budget. It is **read-only by default**: it starts the budget engine read-only, so it sends nothing to the server. It talks to the assistant over standard input and output and opens no network port.
  - To install and run it, follow the "MCP Server" page in the API docs (`api/mcp-server`): build it with `yarn build:mcp` (or use `mcp/mcp.js` from the release artifact), keep the server password in 1Password and pass it with `op run`, and register the server with your assistant.
  - Changes are opt-in: a separate entry started with `--writes` adds tools to create transactions, change a transaction's category, payee or notes, set a budget amount, skip a paycheck and move an account on budget. Each change is recorded in a private audit log before it runs. `--writes` is never allowed for production.

#### Enhancements

- On a phone, Settings has a Notifications row that shows how many entries are unseen, and the Notifications page has a Back button.
- The API has methods for paychecks, business calendars and moving accounts on budget, and names `updatePaycheck` when a script tries to edit a paycheck's schedule.
- The API's `init` takes a `readOnly` option, so a session writes and pushes nothing.

#### Bugfixes

- A schedule form error shows once, instead of also appearing as "Could not search" in the empty transactions list.
- Choosing a date relative to another schedule no longer shows a "Could not search" error before a schedule is chosen.
- When the start date in "Move on budget" is cleared or isn't a real date, the old preview is hidden and a "Choose a start date" hint shows.
- On a phone, the "Categorize moved history?" title shows in full instead of being cut off.
- Fork release cards label their link "View release notes on GitHub" instead of "View on actualbudget.org".
- A release's category counts no longer count the "None in this release." placeholder as a change.
- Two dependencies used by the server are updated to versions that fix reported security issues.
- The MCP server's read tools clean untrusted paycheck text, page the transfers in the Move on budget preview, and report "No matching date" for a repeat rule that never matches.

#### Maintenance

- The MCP server is released as the eighth version-aligned package, and a check fails the build when the eight versions drift.
- The MCP server's tool list is checked against the API's handlers, so a new handler can't ship without a tool decision.
- Agent workflow, branch-protection and OpenSpec housekeeping.

#### Known limitations

- Experimental.
- Upstream changes made after 26.10.0 have not yet been through an upstream release.
- The MCP server runs on your own computer; it is not installed on the server. It needs Node.js 22 or later and the 1Password CLI.
- Each deposit must go to a different account, and every paycheck repeats its defined amounts; edit a posted transaction for a one-off change.
- Imported deposits more than about 7.5% from the expected amount do not link automatically.
- A duplicate of the latest paycheck (for example, imported twice) can hide the next skipped date.
- Releases published on the same day may show the "What's new" message for any of them; the Notifications page lists all.
- No iPhone acceptance test is claimed.
