# Release 26.10.1-alpha.24 — Ken’s Actual fork

November 5, 2026

**Unofficial fork prerelease.** Based on upstream Actual `master` at `21c2b3f703142f858af4c653a31e675ca5ff85d7` (October 26, 2026), which comes after Actual 26.10.0 and is not itself an upstream release; not an official Actual Budget release.

This release lets the hosted assistant connector change your budget, not only read it, on staging and on production.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- The hosted MCP entry (`actual-mcp-http`) is now read-write. It offers the same `write_` tools as the stdio `--writes` entry, with the same limits, and logs each write first to `<data folder>.audit.jsonl` (`production-remote.audit.jsonl` on production) with the caller's OAuth subject. A production host is still served only under the production guard.

#### Enhancements

- The stdio MCP server's `--writes` entry can now be used against a production host when `ACTUAL_MCP_ALLOW_PRODUCTION=1` is set.
- The `sync_budget` tool also sends the local copy's changes where write tools are offered, as the app does.
- The hosted entry's OAuth metadata names the resource "Actual Budget" instead of "Actual Budget (read-only)".

#### Bugfixes

- None.

#### Maintenance

- OpenSpec records for the read-write hosted entry, the shared Auth0 tenant for production identities, the shorter production go-live path and the Amazon order itemization layout.
- Agent hooks also block agents from approving deployments, including through the GraphQL API.
- The MCP README describes the read-write hosted entry.

#### Known limitations

- Experimental.
- Upstream changes made after 26.10.0 have not yet been through an upstream release.
- The hosted MCP container image is built and loaded on the server by hand; it is not part of this release's Docker image.
- The stdio MCP server still runs on your own computer and needs Node.js 22 or later and the 1Password CLI.
- No iPhone acceptance test is claimed.
