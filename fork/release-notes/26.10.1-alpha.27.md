# Release 26.10.1-alpha.27 — Ken’s Actual fork

November 6, 2026

**Unofficial fork prerelease.** Based on upstream Actual v26.11.0 (`1766241e3f4b3c578e424c4fa15f1eb83c0da17d`, October 29, 2026); not an official Actual Budget release.

This release brings in upstream Actual 26.11.0, including its fix for SimpleFIN connection failures, and lets AI assistants using the MCP server create and maintain categories and category groups.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- None.

#### Enhancements

- AI assistants using the MCP server can create, rename, hide, move and delete categories and category groups.

#### Bugfixes

- Fixed SimpleFIN connection failures. The sync server now makes its bank-provider requests (SimpleFIN, GoCardless, Enable Banking and the CORS proxy health check) with the same HTTP client throughout.
- Fixed Tab skipping to the cleared column after picking a transaction date with the mouse.

#### Maintenance

- Upstream Actual 26.11.0 is merged into the fork.
- The sync server now requires Node 22.19.0 or newer.
- OpenSpec records for the MCP category maintenance tools.

#### Known limitations

- Experimental.
- Attached documents aren't included in a budget export, and removed documents stay on the sync server.
- HEIC pictures are refused; use the Photos library or a JPEG or PNG copy.
- Attaching a document needs a connection; there is no offline upload queue.
- No iPhone acceptance test is claimed.
