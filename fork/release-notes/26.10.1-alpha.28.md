# Release 26.10.1-alpha.28 — Ken’s Actual fork

November 7, 2026

**Unofficial fork prerelease.** Based on upstream Actual v26.11.0 (`1766241e3f4b3c578e424c4fa15f1eb83c0da17d`, October 29, 2026); not an official Actual Budget release.

This release lets you create a category straight from the category picker, makes the picker list only categories that match what you type, and makes Sign out end your identity provider session too.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- None.

#### Enhancements

- Create a category from the category picker when nothing matches what you typed, choosing its group, on desktop and phone.
- The desktop app now shows the fork's release notes on the notifications page.

#### Bugfixes

- The category picker no longer lists unrelated categories for loose letter matches.
- Fork builds no longer show upstream's "New version available" notice.
- On the phone transaction editor, notes no longer appear twice.
- On servers using OpenID, Sign out now also signs you out of the identity provider, so the next sign-in asks who you are.

#### Maintenance

- OpenSpec records for the mobile notes view, OpenID sign-out and per-household Auth0 apps.
- Architecture decision record 0009: hosting options for more than one household.
- On servers using OpenID, the sync server now accepts only sign-ins issued for its own app. Nothing changes for users.
- No upstream changes in this release; the fork stays on upstream Actual 26.11.0.

#### Known limitations

- Experimental.
- OpenID sign-out needs the server's address in the identity provider's allowed sign-out addresses; without it the provider shows an error page, though you are already signed out of Actual.
- Attached documents aren't included in a budget export, and removed documents stay on the sync server.
- HEIC pictures are refused; use the Photos library or a JPEG or PNG copy.
- Attaching a document needs a connection; there is no offline upload queue.
- No iPhone acceptance test is claimed.
