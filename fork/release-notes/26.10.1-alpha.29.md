# Release 26.10.1-alpha.29 — Ken’s Actual fork

November 7, 2026

**Unofficial fork prerelease.** Based on upstream Actual v26.11.0 (`1766241e3f4b3c578e424c4fa15f1eb83c0da17d`, October 29, 2026); not an official Actual Budget release.

This release stops taps on a note's tag or file path from opening the note editor on the phone, and makes Sign out on OpenID servers go straight through without the identity provider's confirmation page.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- None.

#### Enhancements

- None.

#### Bugfixes

- On the phone, tapping a tag or file path in a transaction note no longer starts editing the note.
- On servers using OpenID, Sign out no longer stops at the identity provider's "Are you sure?" page.

#### Maintenance

- The sync server now logs a request for a file id it does not know, which makes missing-file reports easier to trace.
- The MCP coverage check skips mock routes.
- End-to-end test runs build the sync server once per run instead of once per fixture, which removes a build collision.
- Clearer wording and types in the MCP category specification and the first-sign-in and production-identity specifications.
- No upstream changes in this release; the fork stays on upstream Actual 26.11.0.

#### Known limitations

- Experimental.
- OpenID sign-out needs the server's address in the identity provider's allowed sign-out addresses; without it the provider shows an error page, though you are already signed out of Actual.
- Attached documents aren't included in a budget export, and removed documents stay on the sync server.
- HEIC pictures are refused; use the Photos library or a JPEG or PNG copy.
- Attaching a document needs a connection; there is no offline upload queue.
- No iPhone acceptance test is claimed.
