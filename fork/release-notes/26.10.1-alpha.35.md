# Release 26.10.1-alpha.35 — Ken’s Actual fork

November 13, 2026

**Unofficial fork prerelease.** Based on upstream Actual v26.11.0 (`1766241e3f4b3c578e424c4fa15f1eb83c0da17d`, October 29, 2026); not an official Actual Budget release.

This release makes the sync server delete documents that were removed from transactions, after a waiting period, instead of keeping them forever.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- The sync server now deletes a document 30 days after every device has reported it removed from its transaction, and deletes a deleted budget's documents 30 days after the budget was deleted. A daily job does the deleting, at most 500 documents per run, and logs each deletion. Undoing a removal, or opening the document, restarts its 30 days. Set `ACTUAL_ATTACHMENTS_ORPHAN_RETENTION_DAYS` to change the waiting period, or to `0` to stop all deletion.
- The server's `/metrics` shows how many bytes of documents are stored, how many are waiting to be deleted, and the result of the last cleanup.

#### Enhancements

- Devices report removed and restored documents to the server when they sync.

#### Bugfixes

- Re-creating a budget you deleted now keeps its documents and starts with no old shares.

#### Maintenance

- No upstream changes in this release; the fork stays on upstream Actual 26.11.0.
- The hosted MCP server's dependency `hono` is updated past five security advisories, and its documents listing treats attachment types and ids as untrusted.
- Native iPhone and Mac app work (native Budget tab, Home Economics icon and theme, accessibility, sign-in and sign-out) and its OpenSpec records; these do not change the server or web image.

#### Known limitations

- Experimental.
- Tapping a tag in the transaction editor does nothing.
- Tags are not yet fully accessible on the phone.
- OpenID sign-out needs the server's address in the identity provider's allowed sign-out addresses; without it the provider shows an error page, though you are already signed out of Actual.
- Attached documents aren't included in a budget export.
- Documents already removed before this release are not tracked, so they are not deleted.
- HEIC pictures are refused; use the Photos library or a JPEG or PNG copy.
- Attaching a document needs a connection; there is no offline upload queue.
- After restoring server data from a backup, pause the cleanup first (`production/RESTORE.md`).
