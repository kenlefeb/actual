# Release 26.10.1-alpha.36 — Ken’s Actual fork

November 14, 2026

**Unofficial fork prerelease.** Based on upstream Actual v26.11.0 (`1766241e3f4b3c578e424c4fa15f1eb83c0da17d`, October 29, 2026); not an official Actual Budget release.

This release fixes three paycheck and schedule problems found in production: a split's payee carrying over into later splits, a schedule that posted a duplicate when its transaction was linked a day or two early, and schedule names missing from the phone's Link schedule dialog. It also makes the sync server's cleanup of a deleted budget's documents safer.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- No new features in this release.

#### Enhancements

- The phone's Link schedule dialog shows each schedule's name. Its header stacks and its rows are sized for a phone screen.

#### Bugfixes

- When a paycheck has deductions entered as splits, a split's payee no longer carries over into the splits after it.
- A schedule that posts automatically with an approximate date now counts a transaction linked up to 2 days before the schedule's date, so it no longer posts a duplicate. The manual approximate-date lookback for daily schedules is unchanged.
- The sync server's removal of a deleted budget's documents is safer: if the budget is uploaded again while the removal is under way, its documents are kept. A deleted budget whose server record is missing now has its documents removed too, and a removal that fails is finished on the next daily run.

#### Maintenance

- No upstream changes in this release; the fork stays on upstream Actual 26.11.0.
- The build for the Mac app (TestFlight for Mac) and the iOS release workflow are wired up: the iOS run records its build, checks the build version and carries a dispatch id in its title. These affect only how the fork's native apps are built and released.
- A sync-server test that timed out on a loaded machine is fixed.
- The OpenSpec record of the attachment cleanup is archived.

#### Known limitations

- Experimental.
- Tapping a tag in the transaction editor does nothing.
- Tags are not yet fully accessible on the phone.
- OpenID sign-out needs the server's address in the identity provider's allowed sign-out addresses; without it the provider shows an error page, though you are already signed out of Actual.
- Attached documents aren't included in a budget export.
- Documents removed before alpha.35 are recorded the first time an updated device syncs, and deleted 30 days after that. Removals made on a device that has not been updated are not tracked.
- HEIC pictures are refused; use the Photos library or a JPEG or PNG copy.
- Attaching a document needs a connection; there is no offline upload queue.
- After restoring server data from a backup, pause the cleanup first (`production/RESTORE.md`).
