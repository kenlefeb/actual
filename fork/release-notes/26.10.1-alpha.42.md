# Release 26.10.1-alpha.42 — Ken’s Actual fork

November 17, 2026

**Unofficial fork prerelease.** Based on upstream Actual v26.11.0 (`1766241e3f4b3c578e424c4fa15f1eb83c0da17d`, October 29, 2026); not an official Actual Budget release.

This release lets the MCP server (the connector that lets Claude read and change a budget) reconcile an account to a statement balance, with the balance confirmed by a person first.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- The MCP can reconcile an account to a statement balance.
- Reconcile needs the new `transactions:reconcile` permission, which a connection's grant must include. It is not granted in production.
- Reconcile also needs a statement balance that a person has confirmed in the app. The assistant cannot supply the balance itself. The screens for recording the balance are still to come, so reconcile cannot be used end to end yet.

#### Enhancements

- The server's operator can set the reconcile limit, and how much clock difference a recorded statement balance tolerates.

#### Bugfixes

- None in this release.

#### Maintenance

- No upstream changes in this release; the fork stays on upstream Actual 26.11.0.
- The reconcile and recorded-statement-balance changes are specified (sc-4213, sc-4793, sc-4800).

#### Known limitations

- Experimental.
- MCP reconcile needs the `transactions:reconcile` scope and a statement balance the human confirmed in the app; the app screens for confirming it are not built yet.
- The hosted MCP still cannot delete anything, because no delete scope (including `accounts:delete`) is granted; adding it is a grants-file change and a deploy.
- The native Schedules & Paychecks screens are off by default; turn them on in Settings to try them.
- Tapping a tag in the transaction editor does nothing.
- Tags are not yet fully accessible on the phone.
- OpenID sign-out needs the server's address in the identity provider's allowed sign-out addresses; without it the provider shows an error page, though you are already signed out of Actual.
- Attached documents aren't included in a budget export.
- Documents removed before alpha.35 are recorded the first time an updated device syncs, and deleted 30 days after that. Removals made on a device that has not been updated are not tracked.
- HEIC pictures are refused; use the Photos library or a JPEG or PNG copy.
- Attaching a document needs a connection; there is no offline upload queue.
- After restoring server data from a backup, pause the cleanup first (`production/RESTORE.md`).
