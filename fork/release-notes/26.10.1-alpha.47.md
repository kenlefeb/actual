# Release 26.10.1-alpha.47 — Ken’s Actual fork

November 20, 2026

**Unofficial fork prerelease.** Based on upstream Actual v26.11.0 (`1766241e3f4b3c578e424c4fa15f1eb83c0da17d`, October 29, 2026); not an official Actual Budget release.

This release fixes the MCP server refusing every write. It also carries database and iPhone storage-safety work that changes how the web app and sync server start.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- None in this release.

#### Enhancements

- None in this release.

#### Bugfixes

- The MCP server refused every write with "The loaded budget has no id" since the undo and audit change shipped, while reads kept working. Writes now work again (#508).
- A database migration and the record that it ran now commit as one transaction, so a migration that stops partway cannot leave the database half-migrated. This also repairs account types that an earlier migration left wrong (#502). **Affects the web app and the sync server Ken uses.**

#### Maintenance

- iPhone storage safety (off unless an iPhone shell turns it on, so web, desktop and the sync server behave as before): the page checks that each write reached storage before saying "Saved", shows storage status and notices, holds sync for writes that are not stored yet, flushes storage when the app goes to the background, and shows page alerts, confirms and prompts through the app (#473, #481 to #483, #485, #487, #490 to #493, #496, #498, #500, #501, #503 to #505). The `native/*` handlers in loot-core are gated and do nothing without a native shell. This build turns the guard on in the iPhone app source, but the iPhone app Ken uses does not get it until a new TestFlight build.
- Native reads now wait for the budget to open (#507). The Mac app reload now closes a page dialog (#506).
- iPhone app: it reloads its own page when the web process ends and tells the person (#484, #489); scheduled splits show the payee the web shows (#471, #472); Accounts amounts stay whole and search stays visible (#476); VoiceOver fixes (#479); the Undo button sits under its text at accessibility sizes (#504); notices wait for the Limits screen (#475).
- Specs, CI and tests: spec records for the storage work and Reconcile alert (#468, #469, #474, #478, #486, #488, #491, #495, #497), a release archive check that scans only compiled code (#477), and iPhone kill and UI test fixes (#480, #499).
- No upstream changes in this release; the fork stays on upstream Actual 26.11.0.

#### Known limitations

- Removing a deduction from a paycheck in the iPhone app can crash. The fix is tracked in sc-5504, and the next iPhone TestFlight build is held for it.
- Experimental.
- The native Schedules & Paychecks screens are off by default; turn them on in Settings to try them.
- Tapping a tag in the transaction editor does nothing.
- Tags are not yet fully accessible on the phone.
- OpenID sign-out needs the server's address in the identity provider's allowed sign-out addresses; without it the provider shows an error page, though you are already signed out of Actual.
- Attached documents aren't included in a budget export.
- Documents removed before alpha.35 are recorded the first time an updated device syncs, and deleted 30 days after that. Removals made on a device that has not been updated are not tracked.
- HEIC pictures are refused; use the Photos library or a JPEG or PNG copy.
- Attaching a document needs a connection; there is no offline upload queue.
- After restoring server data from a backup, pause the cleanup first (`production/RESTORE.md`).
