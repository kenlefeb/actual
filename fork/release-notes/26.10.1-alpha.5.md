# Release 26.10.1-alpha.5 — Ken’s Actual fork

October 27, 2026

**Unofficial fork prerelease.** Based on Actual 26.10.0 (`2bebdbaae0b701120a8cad9d56aafd64fa04c577`); not an official Actual Budget release.

Fork release notes now appear in the app. Open the bell (Notifications) to read what changed in each fork release, and see a "What's new" message the first time you run a new release.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- Show each fork release's notes on the Notifications page, newest first, followed by upstream Actual's announcements included in this build.
- Show "What's new in Actual <version>" the first time a new fork release runs.

#### Enhancements

- Read release notes from the build itself, so a deployment only lists notes for its own and earlier versions and works without reaching GitHub.

#### Bugfixes

- No fork bug fixes in this release; business calendars and earlier mobile and desktop improvements are retained.

#### Maintenance

- Generate the in-app release entries from `fork/release-notes` with `yarn generate:fork-news`; a test fails when a release has no entry.
- Record the rule that every release's notes appear in the app.

#### Known limitations

- Releases published on the same day (alpha.4 and alpha.5) may show the "What's new" message for either one; the Notifications page lists both.
- Fork release cards link to the note on GitHub but are labeled "View on actualbudget.org".
- Upstream announcements after Actual 26.9.0 are not included until the fork merges newer upstream code.
- Schedules using business calendars are not part of this release.
- Synthetic staging only; no real financial data or production paperwork migration. No iPhone acceptance test is claimed.
