# Release 26.10.1-alpha.6 — Ken’s Actual fork

October 27, 2026

**Unofficial fork prerelease.** Based on Actual 26.10.0 (`2bebdbaae0b701120a8cad9d56aafd64fa04c577`); not an official Actual Budget release.

Fork release notes now actually appear on the Notifications page of the web app served by Actual's server. Alpha.5 added them, but its setting only applied to desktop builds, so the server's web app still showed upstream's feed.

Docker Tag: `ghcr.io/kenlefeb/actual-hosting:run-<successful workflow run>-1` (private; see the accompanying `image.ref`, `image.id` and `source.json` for exact provenance).

#### Features

- No new features; this release makes alpha.5's in-app fork release notes work on the server's web app.

#### Enhancements

- No enhancements beyond the fix below.

#### Bugfixes

- Read the bundled fork and upstream release notes in the web app built for the server (browser build mode), instead of fetching upstream's feed from GitHub.

#### Maintenance

- Verify the bundled feed with the same browser build mode the server image uses.

#### Known limitations

- Releases published on the same day (alpha.4, alpha.5 and alpha.6) may show the "What's new" message for any of them; the Notifications page lists all.
- Fork release cards link to the note on GitHub but are labeled "View on actualbudget.org".
- Upstream announcements after Actual 26.9.0 are not included until the fork merges newer upstream code.
- Schedules using business calendars are not part of this release.
- Synthetic staging only; no real financial data or production paperwork migration. No iPhone acceptance test is claimed.
